# TST-003 — Verify SPL, arithmetic, and feature-space contracts

- **Depends on** [TST-001](TST-001.md)
- **Scope** Review the [SPL tests](../../../src/spl_test.cpp), [math tests](../../../src/mathhelper_test.cpp), and [feature analysis tests](../../../src/analysis_test.cpp) against their public contracts. Use table-driven arithmetic values and boundary cases, small SPL truth tables for valid system IDs and availability, and hand-computed feature-space cases for masks, category counts, and lookup behavior. Keep the serialization assertions required by the SPL contract. Replace compiled feature-index checks and cache assumptions with observable outcomes. Track unresolved cases in [M2](../milestones/M2.md).
- **Done when** `make test_spl test_math test_analysis` exercises accepted and rejected inputs, Boolean and cardinality constraints, feature ID and membership rules, arithmetic boundaries, and public errors. Expected system sets and small feature spaces come from fixture truth tables or an independent test calculation.
