Detailed Description

This header provides mathematical helper functions, including safe arithmetic operations, power calculations, factorials, combinations, and a combinations generator class.

The header offers both checked and unchecked arithmetic variants. Checked arithmetic includes overflow and underflow detection, while unchecked provides standard operations.

Controlling Safe vs. Unsafe: The choice between checked and unchecked operations is determined by a preprocessor macro. Define the macro USE_UNCHECKED_ARITHMETIC to enable the less-safe unchecked operations. By default, checked operations are used.
