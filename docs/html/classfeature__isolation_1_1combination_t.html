Detailed Description

template<class T>
class feature_isolation::combinationT< T >

A class for generating combinations of elements from a vector.

This class provides an efficient way to iterate over all possible combinations of a given size (k) from a set of elements provided as a vector. The combinations are generated in an iterative manner. It ensures that the input vector remains unmodified during the combination generation.

Template Parameters
TThe type of the elements in the input vector.

Example Usage

int main() {
std::vector<char> symbols = {'A', 'B', 'C'};
feature_isolation::combinationT<char> combinationsGenerator(symbols, 2); // Combinations of size 2
while (combinationsGenerator.next()) {
std::vector<char> currentCombination = combinationsGenerator();
for (char c : currentCombination) {
std::cout << c << " ";
}
std::cout << std::endl;
}
return 0;
}
