Detailed Description

Provides arithmetic operations without overflow or underflow checks.

This namespace offers a set of arithmetic operations that mirror the standard C++ arithmetic behavior. It does not incorporate overflow or underflow checks. Consequently, these operations might lead to silent wrapping of results if integer overflow or underflow occurs.

Use Cases:

  • Performance-critical sections where the developer can guarantee the absence of overflow/underflow.
  • Code where the potential for overflow or underflow is known to be negligible.

Design Considerations:

  • Prioritizes raw performance over safety.
  • Provides both in-place modification functions (e.g., add_asign) and functions that return new values (e.g., add).
