Detailed Description

Provides utilities for safe and efficient mathematical operations.

This namespace contains facilities for:

  • Checked and unchecked arithmetic operations to manage overflow/underflow.
  • Common mathematical functions (factorial, combinations, etc.).
  • A combinatorial generator class for symbol combinations.

Calculates the number of combinations of k elements from a set of n elements.

This function calculates the number of ways to choose k elements from a set of n elements, without regard to order. Also known as "n choose k", often written C(n, k).

Parameters
nThe size of the set.
kThe number of elements to choose.
Returns
The number of combinations of k elements from a set of size n. Returns 1 if k == 0 or k == n.

Calculates the product of a range of unsigned integers.

This function calculates the product of all unsigned integers in the inclusive range from from to to. Handles edge cases, returns zero if the range is empty from == zero or to == zero, or if from > to.
