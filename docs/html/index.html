Feature Isolation Mathematical Helper Functions

Introduction

This library provides a robust set of mathematical functions and utilities, with a particular emphasis on safety and precision in integer calculations. It is designed to be a helpful tool in applications where arithmetic errors would have significant consequences.

Key Features

  • Checked Arithmetic:
    • Functions for addition, subtraction, and multiplication that rigorously check for potential integer overflow and underflow.
    • Throws std::overflow_error or std::underflow_error if calculations would produce invalid results.
    • Helps prevent silent, unexpected errors caused by exceeding the limits of integer representation.
  • Unchecked Arithmetic:
    • Standard arithmetic operations without overflow/underflow checks.
    • Prioritizes performance in scenarios where the developer can guarantee error-free calculations or where the risk of overflow/underflow is negligible.
  • Power Calculations:
    • Efficiently calculates powers (base raised to an exponent).
    • Includes a specialized function for calculating powers of 2.
  • Factorials:
    • Computes factorials of non-negative integers.
  • Combinations:
    • Calculates the number of combinations of k elements from a set of size n (C(n, k)).
    • Calculates the sum of all the number of combinations of varying sizes up to k elements (k = 0, 1, ..., k).
  • Combinations Generator:
    • Class (combinationT) for iteratively generating all combinations of a given size from a set of elements.
