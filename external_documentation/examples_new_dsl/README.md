These files are documentation copies of the canonical paper-aligned fixtures in
`spl_specs/new_dsl/valid/`. They are kept so the docs can reference stable
example filenames without duplicating or renaming the test fixtures themselves.

- `paper_fx_implies_fy.spl` ↔ `spl_specs/new_dsl/valid/fx_implies_fy.spl`
