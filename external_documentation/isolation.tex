\section{Basic Information and Results}
Feature isolation is based on the following information:
\begin{itemize}
	\item A specification of a software product line including the names of its independent features, the feature categories to be considered, the maximum rank of interaction between any kind of and- and or-features, and optionally explicitly dependent features plus available systems or missing systems all of which resulting in a set with the identifiers of available systems. This specification is denoted by $\mathit{SPL}$. An identifier ($\mathit{ID}$ for short) is a natural number with a lower bound of 1.
    \item For each feature there exists a description that specifies in which systems it occurs and in which it does not plus an associated unique feature $\mathit{ID}$. Such a feature description is called $\mathit{FD}$, a feature $\mathit{ID}$ is called $\mathit{FID}$.
    \item Each system has a description that specifies the features it consists of plus an associated unique system $\mathit{ID}$. Such a system description is called $\mathit{SD}$, a system $\mathit{ID}$ is called $\mathit{SID}$.
\end{itemize}
\paragraph{Evaluation.} To describe the  isolation of a feature $f_i$ based on its  $\mathit{FID}$ and given a system description $\mathit{SD}$ some operations are introduced:
\begin{itemize}
	\item $\mathit{SD}$ can be flattened by replacing all each of its elements by the corresponding set of $\mathit{FID}$s and applying either set intersection, $\bigcap$, or set union, $\bigcup$, to them. 
	\item Flattening $\mathit{SD}$ with $\bigcap$ gives $\widehat{\mathit{SD}}$.
	\item Flattening $\mathit{SD}$ with $\bigcup$ gives $\widecheck{\mathit{SD}}$.
\end{itemize}

The isolation of a feature $f_i$ specified by its $\mathit{FID}$ involves the following steps:

\begin{enumerate}
	\item $I$ is the set with $\mathit{SID}$s of all systems that include $\mathit{FID_i}$.
	\item $U$ is the set with $\mathit{SID}$s of all systems that do \emph{not} include  $\mathit{FID_i}$.
	\item $\widehat{\mathit{I}} \setminus \widecheck{\mathit{U}}$ gives the result of feature isolation which is denoted by $\overline{D}$.
	$\overline{D}$ must not be equal to $\emptyset$ as this would indicate a fundamental error during the preceding steps. $\overline{D}$ can include exactly one element which then must be the $\mathit{FID_i}$. If $\overline{D}$ includes more than one element, one of them must be $\mathit{FID_i}$.
\end{enumerate}
\paragraph {Minimal set differences} Given are the following equations and definitions:
\begin{enumerate}
	\item $D = I \setminus U$
	\item $\overline{D} = \widehat{\mathit{I}} \setminus \widecheck{\mathit{U}}$
	\item $I_S \subseteq I$
	\item $U_S \subseteq U$
	\item $D_S \subset D \coloneq \mathit{I_S} \subset I \lor \mathit{U_S} \subset U$
	\item $\mathcal{P}(D) = \forall (_\mathit{I_S \setminus U_S}) \in \mathcal{P}(I) \times \mathcal{P}(U)$
	\item \label{minimality} $\mathit{minimal}(D) \coloneq \forall _\mathit{D_S} \in{\{\mathit{\mathcal{P}(D) \setminus D}\}} \land \overline{D_S} \neq \overline{D}$
	\item IT WOULD BE NICE TO ALSO PROVIDE A DEFINITION FOR M.
\end{enumerate} 

From \ref{minimality}  follows that any $D$ that evaluates to $\overline{D}$ is  \emph{minimal} if there is no proper subset of $D$ which gives $\overline{D}$.

In addition, there exists at least one subset of $D$ which gives $\overline{D}$, namely $D$. There can be more than one proper subset of $D$ which also gives $\overline{D}$. The set that includes all different subsets of $D$ that evaluate to $\overline{D}$, is called $M$. $|M| \geq 1$.

\section{Functions, Datatypes and Variables}
\begin{itemize}
	\item The datatypes \code{feature\_ids\_t} and \code{system\_ids\_t} represent the set types for $\mathit{FID}$s and $\mathit{SID}$s.
	\item The member variable \code{spl\_specification\_t::m\_avail\-able\_\-systems} which is of type  \code{sys\-tem\_ids\_t} contains the $\mathit{SID}$s of the actually available systems.
	\item \code{difference\_t} is the type that represents a single set difference. It defines the data members \code{I} and \code{U}, both of type \code{system\_ids\_t}.They represent the operands $I$ and $U$ of a set difference that isolates a feature $f_i$.
	\item \code{minimal\_differences\_t} represents $M$. It defines the data members \code{features} which is of type \code{feature\_ids\_t} and represents $D$
\end{itemize}
