\section{Basic Information and Results}
Feature isolation is based on the following information:
\begin{itemize}
	\item A specification of a software product line including the names of its independent features, the feature categories to be considered, the maximum rank of interaction between any kind of and- and or-features, and optionally explicitly dependent features plus available systems or missing systems all of which resulting in a set with the identifiers of available systems. This specification is denoted by $\mathit{SPL}$. An identifier ($\mathit{ID}$ for short) is a natural number with a lower bound of 1.
    \item For each feature there exists a description that specifies in which systems it occurs and in which it does not plus an associated unique feature $\mathit{ID}$. Such a feature description is called $\mathit{FD}$, a feature $\mathit{ID}$ is called $\mathit{FID}$.
    \item Each system has a description that specifies the features it consists of plus an associated unique system $\mathit{ID}$. Such a system description is called $\mathit{SD}$, a system $\mathit{ID}$ is called $\mathit{SID}$.
\end{itemize}
\paragraph{Evaluation.} To describe the  isolation of a feature $f_i$ based on its  $\mathit{FID}$ some operations are introduced.
\begin{itemize}
	\item Given is a system description $\mathit{SD}$.
	\item $\mathit{SD}$ can be flattened by replacing all each of its elements by the corresponding set of $\mathit{FID}$s and applying either set intersection, $\bigcap$, or set union, $\bigcup$ to them. 
	\item If $\mathit{SD}$ is flattened by applying $\bigcap$ the result is $\widehat{\mathit{SD}}$.
	\item If $\mathit{SD}$ is flattened by applying $\bigcup$ the result is $\widecheck{\mathit{SD}}$.
\end{itemize}


Next, the isolation of a feature $f_i$ specified by its $\mathit{FID}$ is described:

HERE IS STILL A BIG PROBLEM: IT MUST BE WELL DIFFERENTIATED BETWEEN SETS THAT ARE NOT FLATTENED AND SETS THAT ARE FLATTENED AND FLATTENED SETS THAT ARE EVALUATED AS WELL!

\begin{enumerate}
\item $I$ is the set with $\mathit{SID}$s of all systems that include $f_i$ with $\mathit{FID_i}$.
\item $U$ is the set with $\mathit{SID}$s of all systems that do \emph{not} include  $f_i$ with $\mathit{FID_i}$.
\item Each element of $I$ is replaced with the set of its corresponding $\mathit{SD}$s. The resulting nested set is flattened by applying set intersection to all elements. This is denoted by $\bigcap I$.
\item Each element of $U$ is replaced with the set of its corresponding $\mathit{SD}$s.   The resulting nested set is flattened by applying set union to all elements. This is denoted by $\bigcup I$.
\item The set difference $\mathit{DF} = \bigcap I\setminus \bigcup U$ is the result of feature isolation. $\mathit{DF}$ must not be equal to $\emptyset$, as this would indicate a fundamental error during preceding steps. $\mathit{DF}$ can include exactly one element which then must be the $\mathit{FID}$ of $f_i$, i.e. $\mathit{FID_i}$. It $\mathit{DF}$ includes more than one element, one of them must be $\mathit{FID_i}$.
\end{enumerate}
\paragraph {Minimal set differences.} Given $D =  I \setminus U$ and $\mathit{D_S} = \mathit{I_S} \subseteq I \setminus \mathit{U_S} \subseteq U$. Additionally, $\mathit{D_S}$ is a proper subset of $D$ if $\mathit{I_S} \subset I \lor \mathit{U_S} \subset U$ is true. Then any set difference $D_i$ which evaluates to $D_S$ is minimal if there is no strict subset of $D_i$ which also evaluates to $D_S$.\\
For $D$ must exist at least one subset which evaluates to $D_S$, namely $D$. It is possible that for $D$ exist more than one different proper subsets which all evaluate to $D_S$. The set which includes all different subsets of $D$ that evaluate to $D_S$ is called $M$. $|M| \geq 0$.\\
The property of being minimal can also be generalized to $I$ and $U$. A subset of $I$ is minimal if there is no other proper subset of $I$ which evaluates to the same set of $\mathit{FID}$s after flattening. A subset of $U$ is minimal if there is no other proper subset of $U$ which evaluates to the same set of $\mathit{FID}$s  after flattening.

The following examples illustrate the meaning of \emph{minimal} in a set difference (the elements are $\mathit{FID})$s. Given are the systems \\
$ \mathit{SD}_1 = \{ 1, 2, 3 \} $, \\
$ \mathit{SD}_2 = \{ 2, 3, 4 \} $, \\
$ \mathit{SD}_3 = \{ 3, 4, 5 \}$, \\
$ \mathit{SD}_4 = \{ 4, 5, 6 \}$, \\
$ \mathit{SD}_5 = \{ 2, 7 \}$ and \\
$ \mathit{SD}_6 = \{ 1, 8 \}$.


With respect to $FID_2$, the following set intersections $I$ are minimal as they all isolate $\mathit{FID}_2$.\\
$I_1 = \mathit{SD}_1 \cap \mathit{SD}_2$\\
$I_2 = \mathit{SD}_1 \cap \mathit{SD}_5$\\
$I_3 = \mathit{SD}_2 \cap \mathit{SD}_5$

$I_4 = \mathit{SD}_1 \cap \mathit{SD}_2 \cap \mathit{SD}_5$ is not minimal because $I_1$, $I_2$ and $I_3$ successfully isolate $\mathit{FID}_2$ but contain less operands. It is important to note that only evaluating $I$ can give the desired result. Furthermore, $I$ cannot be omitted.

With respect to $\mathit{FID}_2$ the set difference $D_1 = \mathit{SD}_1 \setminus \mathit{SD}_3 \cup \mathit{SD}_6$ is minimal as it isolates $\mathit{FID}_2$.

$D_2 = \mathit{SD}_1 \cap \mathit{SD}_2 \setminus \mathit{SD}_3$ is not minimal, as $I$ already isolates $\mathit{FID}_2$. $D_3 = \mathit{SD}_1 \setminus \mathit{SD}_3 \cup \mathit{SD}_4 \cup \mathit{SD}_6$ is also not minimal, as $\mathit{SD}_3 \cup \mathit{SD}_6$ in $U$ already removes all unwanted elements of $I$. It has to be emphasized, that ---different from $I$--- $U$ can be omitted.

\section{Functions, Datatypes and Variables}
\begin{itemize}
	\item The datatypes \code{feature\_ids\_t} and \code{system\_ids\_t} represent the set types for $\mathit{FID}$s and $\mathit{SID}$s.
	\item The member variable \code{spl\_specification\_t::m\_avail\-able\_\-systems} which is of type  \code{sys\-tem\_ids\_t} contains the $\mathit{SID}$s of the actually available systems.
	\item \code{difference\_t} is the type that represents a single set difference. It defines the data members \code{I} and \code{U}, both of type \code{system\_ids\_t}.They represent the operands $I$ and $U$ of a set difference that isolates a feature $f_i$.
	\item \code{minimal\_differences\_t} represents $M$. It defines the data members \code{features} which is of type \code{feature\_ids\_t} and represents $D$
\end{itemize}
